# H-Point · карта рабочей папки

Открой **эту папку `HPoint/`** в редакторе. Здесь находятся `run.py`, `README.md` и рабочая копия Git. Текущая ветка — `codex/flutter-app`.

| Задача | Где смотреть |
| --- | --- |
| Разобраться в проекте | [README.md](README.md), [план развития](docs/DEVELOPMENT_ROADMAP.md). |
| Запустить сайт | `run.py` читает `.env`. `.env.example` содержит шаблон, `requirements.txt` — зависимости Python. |
| Запустить демо | `scripts/demo_pitch.py` создаёт отдельную SQLite и выдаёт учебные аккаунты. [Сценарий показа](docs/demo/PITCH_RUNBOOK.md). |
| Изменить сайт | `hpoint/web.py` содержит страницы и HTTP-маршруты, `assets/` — стили, скрипты браузера и изображения. |
| Изменить заявки, подбор и чаты | `hpoint/services.py` — заявки и Smart Match, `hpoint/workflow.py` — сценарии помощи, `hpoint/chat_threads.py` — переписки. |
| Изменить «Для работы» | В `hpoint/`: `commercial.py` — кабинет, клиенты и услуги, `commercial_team.py` — команда и проекты, `work_inquiries.py` — обращения, `work_profiles.py` — модули профессий, `estimate_exports.py` — экспорт смет. |
| Изменить базу и тарифы | `hpoint/database.py`, `hpoint/config.py`, `hpoint/billing.py`. [Условия подписок](docs/SUBSCRIPTIONS.md). |
| Изменить Telegram-бота | `run_bot.py` запускает бота, `hpoint/handlers.py` обрабатывает команды. |
| Изменить или собрать Android | [mobile/README.md](mobile/README.md) содержит команды сборки. В `mobile/lib/` лежат экраны и клиент API. |
| Проверить изменения | `tests/` — сервер и браузер, `mobile/test/` — Flutter, `.github/workflows/` — проверки GitHub. |
| Обслуживать сервер | `compose.yaml`, `Dockerfile`, `Caddyfile` и `scripts/`. [Инструкция развёртывания](docs/DEPLOYMENT.md). |

## Быстрый запуск

В PowerShell из этой папки:

```powershell
.\.venv\Scripts\python.exe scripts\demo_pitch.py --serve
```

Открой [локальный сайт](http://127.0.0.1:8088). Логин рабочего кабинета — `owner@example.test`, пароль появится в терминале. Перед изменениями выполни `git status --short -b`, после — проверь сценарий и посмотри `git diff`.

## Справка по папкам

- `docs/` — эксплуатация и правила продукта, `docs/demo/` — материалы для показа, `docs/qa/` — отчёты.
- `.venv/` — зависимости Python. `.env` и `hpoint.db` — локальная конфигурация и SQLite. В Git их не добавляют.
- `.pitch-demo/` — учебные сеансы, `.runtime/` — служебные файлы локальной эксплуатации.
- `.theme-qa/` — результаты проверок и отдельная рабочая копия Git. Прежние снимки выкладок лежат в `release-snapshots/`, старые локальные базы — в `legacy-local/` внутри этой папки.

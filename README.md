# H-Point

**H-Point — Web-first сервис взаимопомощи с Telegram-клиентом.**

H-Point позволяет пользователям размещать заявки на помощь и находить подходящих помощников поблизости.

## Возможности

### Веб-сайт

- регистрация и вход;
- профиль пользователя;
- создание заявок;
- поиск и просмотр заявок;
- Smart Match;
- подбор кандидатов;
- мои кандидаты;
- история заявок;
- рейтинги и отзывы;
- чат;
- карта;
- Telegram-привязка;
- H-Point+;
- система платежей.

### Telegram-бот

Telegram является полноценным клиентом H-Point и работает с той же базой данных и бизнес-логикой, что и веб-сайт.

Поддерживаются:

- регистрация;
- создание заявки;
- поиск помощи;
- Smart Match;
- подбор кандидатов;
- мои кандидаты;
- принятие/назначение кандидата;
- история;
- профиль;
- рейтинги;
- чат;
- уведомления;
- Telegram-привязка.

# H-Point

«Для работы» поддерживает совместные кабинеты организаций: сотрудники и роли,
объекты, задачи, смены, записи клиентов, сметы, показатели работы и публичные
страницы услуг. Доступ, публикация и проверочные сценарии описаны в
[WORKSPACE_QA.md](WORKSPACE_QA.md).

Обзор рабочего дня, поиск по кабинету, быстрые связанные записи и экспорт
расписания в календарь описаны в [проверках удобства кабинета](WORKSPACE_MODERNIZATION_QA.md).

Из публичных услуг можно отправлять приватные обращения с фото. Организация
отвечает во входящих, назначает сотрудника и создаёт клиента и запись.
Администратору доступна воронка с отдельными группами пилота и демо.
[Запуск локального демо и сценарий презентации](PITCH_RUNBOOK.md).

Для выступления подготовлены [речь и ответы жюри](DEMO_DAY_SPEECH.md),
[план развития на 90 дней](DEVELOPMENT_ROADMAP.md).
Полный браузерный прогон на временных базах: `python tests/run_browser_qa.py`.

Доступны девять профессиональных профилей со своими инструментами: тренировки и
замеры подопечных, уроки и домашние задания, процедуры, ремонтные заказы, этапы
строительства, события, группы и посещаемость. Рабочее меню адаптируется под
выбранный профиль. Компактное управление и напоминания в Telegram открываются
только участникам оплаченного рабочего кабинета; включение напоминаний — вручную.

**H-Point — сервис взаимопомощи с веб-сайтом и Telegram-ботом.**

H-Point позволяет пользователям размещать заявки на помощь и находить подходящих помощников поблизости.

## Возможности

### Веб-сайт

- регистрация и вход;
- профиль пользователя;
- создание заявок;
- поиск и просмотр заявок;
- Smart Match;
- подбор кандидатов;
- мои кандидаты;
- история заявок;
- рейтинги и отзывы;
- чат;
- карта;
- Telegram-привязка;
- H-Point+;
- тестовый кошелёк и подписки.

### Telegram-бот

Бот и сайт используют одну базу и общую бизнес-логику. Локально используется SQLite; production-конфигурация Docker использует PostgreSQL.

Поддерживаются:

- привязка к подтверждённому email-аккаунту через одноразовый код;
- уведомления о помощи и достижениях;
- управление помощью при действующем PRO;
- краткое управление рабочим днём и добровольные напоминания при оплаченном
  доступе к рабочему кабинету;
- ссылки на остальные функции сайта.

Регистрации и входа через Telegram нет: сначала создайте и подтвердите
email-аккаунт на сайте. Привязку Telegram можно отменить в профиле.

Команда `/ask` и поле уточнения Smart Match используют локальный объяснимый подбор по категории, профилю, рейтингу, расстоянию и приоритету. Внешняя ИИ-модель не подключена: для неё нужен отдельный провайдер, ключ и правила обработки персональных данных.

Помощь завершает только автор заявки после её выполнения. Помощник не может закрыть заявку. При завершении бесплатной помощи списываются и начисляются HP; для платной помощи автор подтверждает перевод вознаграждения из резерва. Предварительное сообщение помощника о выполнении не требуется.

## Архитектура

Сайт и Telegram-бот используют общую базу данных и общую бизнес-логику.

```text
                    H-Point
                       |
             +---------+---------+
             |                   |
          Website             Telegram
             |                   |
             +---------+---------+
                       |
                 Shared services
                       |
             SQLite / PostgreSQL database
```

## Локальный запуск

### Тестовый бонус в рублях

`REGISTRATION_BONUS_RUB=10000` начисляет новым профилям 10 000 тестовых ₽ в кошелёк
отдельно от HP. Docker Compose включает эту кампанию по умолчанию.
Для существующих профилей выполните один раз
`docker compose exec -T app python scripts/grant-registration-bonus.py`.
Повторный запуск не начисляет бонус повторно и не восстанавливает потраченное.
Начисление записывается в историю как тестовое. Для остановки новых бонусов
задайте `REGISTRATION_BONUS_RUB=0` и пересоздайте контейнеры сайта и бота.

Скопируйте `.env.example` в `.env` и настройте email-доставку. `BOT_TOKEN` и `BOT_USERNAME` нужны только для необязательного связанного бота; вход и регистрация доступны по email.

```powershell
python run.py
```

Эта команда запускает сайт и бота вместе. Чтобы запускать их раздельно, установите `RUN_TELEGRAM_BOT=0` в `.env` и откройте два окна PowerShell в папке проекта:

```powershell
python run.py
python run_bot.py
```

В таком режиме Telegram получает обновления только через `run_bot.py`. Сайт и бот используют одну базу данных, поэтому у привязанного пользователя общие профиль, заявки и история.

## Развёртывание на VPS

Для запуска production-версии на Ubuntu используйте [короткую инструкцию развёртывания](DEPLOYMENT.md): она запускает сайт, базу, Telegram-бота и HTTPS через Docker Compose. Устанавливать Nginx и Python-зависимости на VPS отдельно не требуется.

## Игры и достижения за помощь

Игры временно отключены по умолчанию (`GAMES_ENABLED=0`). Ссылки и игровые
достижения убраны с сайта и из меню бота; старые кнопки и игровые API не
запускают игры, не списывают HP и не выдают награды. Игровые модули,
сохранённые партии, покупки, рекорды и прежний баланс сохраняются.
Для возвращения игр предусмотрен `GAMES_ENABLED=1` с перезапуском сайта и бота.

В профиле доступны разовые достижения за завершённую бесплатную помощь
с оценкой автора 4–5: первое дело — 10 HP; 5 дел для минимум 3 людей — 25 HP;
10 дел для минимум 5 людей — 50 HP; 3 категории для минимум 3 людей — 20 HP;
по 5 звёзд от 5 разных людей — 30 HP. Все пять наград дают суммарно 135 HP
на профиль. Награды добавляются к общему балансу сайта и бота.

За новые дела награда начисляется при оценке автора. За старую помощь
заслуженные награды можно получить кнопкой в профиле или в боте через
«Достижения за помощь» (`/achievements`). Просмотр условий не начисляет HP.
Повторные и одновременные запросы не выдают награду дважды. История наград
переносится вместе с профилем при связывании и отвязке Telegram.

# H-Point

**H-Point — сервис взаимопомощи с веб-сайтом и Telegram-ботом.**

H-Point позволяет пользователям размещать заявки на помощь и находить подходящих помощников поблизости.

## Возможности

### Веб-сайт

- регистрация и вход;
- профиль пользователя;
- создание заявок;
- поиск и просмотр заявок;
- Smart Match;
- подбор кандидатов;
- мои кандидаты;
- история заявок;
- рейтинги и отзывы;
- чат;
- карта;
- Telegram-привязка;
- H-Point+;
- система платежей.

### Telegram-бот

Бот использует ту же SQLite-базу и бизнес-логику, но набор функций отличается от сайта.

Поддерживаются:

- регистрация;
- создание заявки;
- поиск помощи;
- Smart Match;
- подбор кандидатов;
- мои кандидаты;
- принятие/назначение кандидата;
- история;
- профиль;
- рейтинги;
- уведомления;
- Telegram-привязка.

Встроенный AI-ассистент и AI-подбор пока не реализованы. Smart Match использует текущие правила категорий, рейтинга, расстояния и приоритета заявки.

Сайт и Telegram-бот используют общую базу данных и общую бизнес-логику.

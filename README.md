# H-Point

**H-Point — сервис взаимопомощи с веб-сайтом и Telegram-ботом.**

H-Point позволяет пользователям размещать заявки на помощь и находить подходящих помощников поблизости.

## Возможности

### Веб-сайт

- регистрация и вход;
- профиль пользователя;
- создание заявок;
- поиск и просмотр заявок;
- Smart Match;
- подбор кандидатов;
- мои кандидаты;
- история заявок;
- рейтинги и отзывы;
- чат;
- карта;
- Telegram-привязка;
- H-Point+;
- система платежей.

### Telegram-бот

Бот и сайт используют одну базу и общую бизнес-логику. Локально используется SQLite; production-конфигурация Docker использует PostgreSQL.

Поддерживаются:

- регистрация;
- создание заявки;
- поиск помощи;
- Smart Match;
- подбор кандидатов;
- мои кандидаты;
- принятие/назначение кандидата;
- история;
- профиль;
- рейтинги;
- уведомления;
- вход и подтверждение аккаунта через Telegram;
- Telegram-привязка через одноразовый код.

Команда `/ask` и поле уточнения Smart Match используют локальный объяснимый подбор по категории, профилю, рейтингу, расстоянию и приоритету. Внешняя ИИ-модель не подключена: для неё нужен отдельный провайдер, ключ и правила обработки персональных данных.

## Архитектура

Сайт и Telegram-бот используют общую базу данных и общую бизнес-логику.

```text
                    H-Point
                       |
             +---------+---------+
             |                   |
          Website             Telegram
             |                   |
             +---------+---------+
                       |
                 Shared services
                       |
             SQLite / PostgreSQL database
```

## Локальный запуск

Скопируйте `.env.example` в `.env` и укажите `BOT_TOKEN`. Чтобы пользователи могли входить на сайт через Telegram, также укажите `BOT_USERNAME` без символа `@`.

```powershell
python run.py
```

Эта команда запускает сайт и бота вместе. Чтобы запускать их раздельно, установите `RUN_TELEGRAM_BOT=0` в `.env` и откройте два окна PowerShell в папке проекта:

```powershell
python run.py
python run_bot.py
```

В таком режиме Telegram получает обновления только через `run_bot.py`. Сайт и бот используют одну базу данных, поэтому у привязанного пользователя общие профиль, заявки и история.

## Развёртывание на VPS

Для запуска production-версии на Ubuntu используйте [короткую инструкцию развёртывания](DEPLOYMENT.md): она запускает сайт, базу, Telegram-бота и HTTPS через Docker Compose. Устанавливать Nginx и Python-зависимости на VPS отдельно не требуется.

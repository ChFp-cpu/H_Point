Рабочая папка H-Point

Материалы проекта · Презентации · Android APK · Инструкции

Где что менять

  • hpoint — сервер, заявки, Smart Match, кабинеты и Telegram-бот.
  • assets — стили, скрипты и картинки сайта.
  • mobile — Android и iOS.
  • tests — проверки сервера и сайта.
  • scripts — демо, выкладка и резервное копирование.
  • docs — инструкции, материалы показа и отчёты.

Какой именно файл открывать для каждой задачи

Запустить демо

Открой PowerShell в папке HPoint и выполни:

.\.venv\Scripts\python.exe scripts\demo_pitch.py --serve

Затем открой локальный сайт. Логин рабочего кабинета owner@example.test, пароль появится в терминале.

Технические файлы

run.py запускает сайт, .env хранит настройки, hpoint.db — локальную базу, а requirements.txt перечисляет зависимости. Чтобы увидеть эти файлы в Проводнике, включи «Вид → Показать → Скрытые элементы». README репозитория.

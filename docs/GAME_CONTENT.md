# Учебные сценарии игр

Источник сценариев находится в `hpoint/game_content.py`. Это версионируемый
серверный каталог, а не данные браузера.

- Каждый сценарий имеет стабильный `id`, версию, статус публикации, сложность,
  теги, текст, варианты и серверный правильный ответ/разбор.
- В H-Safety и H-Mission опубликовано не менее 20 сценариев. Одна игровая
  сессия получает шесть случайных сценариев.
- При старте сервер сохраняет снимок выбранных сценариев внутри игровой
  сессии. Поэтому последующая правка каталога не изменит уже начатую игру.
- Таблица `game_scenario_history` не даёт повторять сценарий конкретному
  участнику, пока он не увидит весь опубликованный набор. После исчерпания
  набора начинается новый цикл; внутри одной сессии повторов нет.
- API передаёт браузеру только текст текущего вопроса и варианты. Поля
  `correct`, баллы и объяснения остаются в сохранённом серверном состоянии до
  ответа пользователя.

Чтобы добавить сценарий, используйте `_safety` или `_mission` в этом модуле,
задайте новый неизменяемый идентификатор и обновите `CONTENT_VERSION`, если
изменяется смысл уже опубликованного материала. Не меняйте ответ или текст
сценария, на который может ссылаться незавершённая сессия: добавьте новую
версию с новым `id` и снимите старую с публикации после завершения её цикла.
